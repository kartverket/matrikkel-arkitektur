En norsk kommune. Alle matrikkelenheter ligger innenfor èn og bare en bestemt kommune.<br/><br/>Kommunaldepartementet forvalter Kommuneregisteret, og endringer legges manuelt inn i Matrikkelen.<br/>

Notes: Liste over gårdsnummer som enten er benyttet eller godkjent benyttet av kommunen<br/>
eksklusivBruker Private String
Notes: Brukernavn for bruker som har eksklusiv tilgang til å oppdatere data i kommunen. Er tenkt at bare skal være gitt hvis kommunen er låst og godkjent.<br/>
gyldigTilDato Private Date
Notes: Eventuell dato for når kommunen utgikk.<br/>
id Private KommuneId
Notes: Id for en kommune.<br/>
kommunenavn Private String
Notes: Navn på kommune. Navnet er ikke entydig.<br/>
kommunenummer Private String
Notes: Firesifret entydig kommunenr. Skal skrives med ledende nuller.<br/>
konverteringStatus Private String
Notes: Status etter konvertering. Denne skal inneholde en tekst med når konvertering til produksjonsdatabasen er godkjent av iverksettingsteamet. Når feltet er null er konverteringen ikke godkjent enda og oppdateringer på kommunen i produksjonsdatabasen skal ikke være mulig. <br/>
last Private Boolean
Notes: Flagger om denne kommunen er låst for oppdateringer. Settes når uttak fra GAB starter for sluttkonvertering av konverteringsgruppen som kommunen tilhører, og låses opp når sluttkonverteringen er godkjent for konverteringsgruppen. Kommunen kan også låses for oppdateringer senere av andre årsaker.<br/>
nedsattKonsesjonsgrense Private boolean
Notes: Dersom satt så har kommen nedsatt eller delvis nedsatt konsesjonsgrense. <br/>Dette vil si at dokumentasjonsfritak i forskrift om konsesjonsfrihet ikke gjelder for denne kommunen og erverver må sende inn egenerklæring for å dokumentere konsesjonsfrihet<br/>
senterpunkt private Position
Notes: Senterpunkt for kommunen, og det punktet kartet vil sentreres på når man går inn i kommunen.<br/>
